# Convocatorias Andalucía – datos

Histórico de anuncios de empleo público de la administración local de las 8 provincias de Andalucía (BOE, BOJA y BOP), excluida Policía Local. Se actualiza cada día laborable a las 8:00.

Panel: https://convocatorias-andalucia.pplx.app

Fuentes oficiales: BOE, BOJA y Boletines Oficiales de las Provincias. Fin de plazo estimado sin festivos; consulte siempre las bases.
